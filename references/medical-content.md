# 病例内容与医学一致性

## 病例性质与来源

- **真实病例（已脱敏）**：仅依据操作者提供的病历资料填写患者事实；没有记录的内容写“未提供”或“待核实”，不能借用病例库补成真实患者经历。PPT 标注“真实病例（已脱敏）”，并按机构要求核查展示权限与脱敏程度。
- **虚构教学病例**：病例库和自行构造的病例均属此类。PPT 标注“虚构教学病例”；数值、时间、处置与结局应形成可审查的完整叙事，不能随机设定结局或把改造后的数值说成真实记录。临床人员审核医学合理性后再用于教学。
- 在标题页或资料来源页展示上述性质，并在交付说明中重复标注。若资料混用或来源不清，先澄清，不输出貌似真实的病例汇报。

## 病例图片与图像来源

- 真实病例可使用同一病例的影像、病理、内镜、皮损或检查图片；先确认展示授权与机构规定，制作去标识化副本。检查画面角标、烧录文字、DICOM 元数据、文件名、备注和 PPT 内嵌原图，避免仅用裁剪或遮挡后仍可还原身份信息。
- 在图旁标注检查类型、采集时点、关键所见与必要的定位；只标有证据支持的病灶，不把影像表现写成未经证实的诊断。裁剪应保留判断所需上下文，避免过度锐化或修改病灶。
- 虚构教学病例可使用经授权的公开教学图片，但必须在图旁标“示例图片，非本病例检查”，并注明来源；在备注或资料来源页保留作者、许可、原图链接和访问日期。不得让读者误以为图片来自该虚构患者。图库图片、AI 生成图仅作示意，不充当患者检查或诊断证据。
- 需要公开图片时，按病种、检查方式和关键影像表现检索，优先查看 [CDC PHIL](https://phil.cdc.gov/)、[Wikimedia Commons](https://commons.wikimedia.org/) 和 [NLM Open-i](https://openi.nlm.nih.gov/) 的原始文件页。逐张核对医学相关性、分辨率、可见水印、作者、许可及目标用途；CDC PHIL 和 Open-i 的图片权限也因具体条目而异。
- 优先获取许可适用的无水印原图。若只有带水印版本，先寻找同一来源提供的合法无水印版本；仅对自有图片或获得明确去水印及修改授权的图片执行去水印。保存原图和授权记录，处理后核对图像与原始检查内容，不能改变病灶、标尺、方向标记或其他诊断信息。许可不清或不允许修改时换图；无水印不等于可自由使用。记录原图页面、作者/机构、许可、所需署名和下载日期，按许可在幻灯片可见位置及备注/资料来源页署名。
- 找不到合适且可合法使用的图片时，用文字、结构化结果或示意图表达，不强行配图；未经授权的患者图片不得上传至外部图片搜索、生成或编辑服务。

## 统一病例数据源

先建立下表（可在备注、受控草稿或结构化数据中维护），再从中填充所有幻灯片。若操作者自行提供了详细病例资料（病史、查体、检验、影像、诊断、治疗等），以提供资料为唯一事实来源，逐项填入下表；仅补全格式与表述，不补造未提供的内容。

| 模块 | 最低字段 | 核验 |
| --- | --- | --- |
| 基本资料 | 去标识化年龄段、性别、入院/就诊时间线 | 不出现姓名、证件、电话、住址、病案号等标识符 |
| 主诉与现病史 | 症状、起病、病程、关键阴阳性、时间点 | 与后续诊断和处置时间线一致 |
| 既往史/用药/过敏史 | 相关风险因素和否认项 | 不把未提供内容写成“无” |
| 查体 | 阳性体征、关键阴性体征、检查时间 | 不混淆入院、复查和出院时状态 |
| 辅助检查 | 名称、值、单位、参考范围、时间、来源 | 数字、单位、上下箭头和引用一致 |
| 诊断 | 初步/最终诊断、鉴别诊断及证据 | 明确诊断阶段；不把鉴别写成确诊 |
| 治疗与转归 | 措施、剂量/频率（如已提供）、观察结果、时间 | 因果表述有证据；不夸大疗效 |
| 反思 | 问题、原因、改进 | 区分病例事实和教学观点 |

## 诊断证据链

诊断页应让听众能顺着证据得到结论：

```text
病史关键点 → 阳性体征 → 异常检查/特异性证据 → 排除或鉴别要点 → 诊断结论
```

- 每一环只保留改变诊断概率或处置的要点；不要堆叠无关正常值。
- 将关键阳性事实、异常数值和最终诊断的关键短语标为 `#EE0000`；同一页的红色只承担“诊断证据”这一语义。
- 红色不是替代解释：数值旁保留单位、参考范围、检查日期/时点；影像/病理须说明检查类型与日期。
- 用“支持”“提示”“与……一致”“待结合……”表达证据强度；没有充分依据时不写“证实”。

## 一致性检查

逐项比对：

1. 年龄、性别、生理状态与疾病/治疗是否相容；
2. 所有日期是否按病程先后排列，且“入院、检查、干预、复查、出院”互不矛盾；
3. 检查值、单位、参考范围和异常方向是否在各页一致；
4. 初步诊断、鉴别诊断、最终诊断之间是否清楚区分；
5. 治疗的适应证、时序、剂量和疗效陈述是否能回链到已提供资料；
6. “无/否认/正常/改善/治愈”等绝对措辞是否有来源；否则改为“未提供”“未见记录”或“待核实”。

发现矛盾时，优先保留原始资料与时间戳，在页面/交付说明中列为待核实项；不得自行选择看似更合理的一种。

## 去标识化

移除或泛化直接标识符与可组合识别线索：姓名、照片、证件号、联系方式、住址、精确生日、病案号、条码、完整住院号、机构内可回溯链接及截图中的同类信息。影像截图、检验单和页眉页脚都需单独检查。

保留教学必要性与最小化原则：年龄用区间或“××岁”按授权展示；时间可相对化为“入院第 N 天”。如机构有自己的脱敏标准，以机构要求为准。

病例性质须在 PPT 标题页或资料来源页明确展示：虚构内容写“虚构教学病例”，真实病例写“真实病例（已脱敏）”。不要用隐藏于备注或仅在交付说明中披露的方式代替页面标注。

## 临床边界

本技能用于呈现和一致性审查，不提供患者个体化诊疗决策。最终诊断、治疗方案、药物剂量和对外病例材料应由具备资质的临床人员审核确认。
