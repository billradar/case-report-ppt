# 最终质检与交付

## 内容与医学检查

- [ ] 所有页面均回链到统一病例数据源；日期、数值、单位、范围和诊断名称前后一致。
- [ ] 初步诊断、鉴别诊断、最终诊断分层明确；诊断页形成完整证据链。
- [ ] 异常指标/关键阳性证据为 `#EE0000`，且仍有单位、范围、时间和必要解释。
- [ ] 不确定、缺失或矛盾信息已标为待核实，未被编造成事实。
- [ ] 已完成去标识化：包括截图、影像角标、页眉页脚、备注、超链接和文件属性（若可访问）。

## 模板与视觉检查

- [ ] 页面尺寸、主题、主背景、Logo、核心字体、页眉页脚、页码和源页序均保持，除非有书面授权。
- [ ] 标题、正文、颜色、边距和对齐在同类页一致；无文字遮挡、溢出、重叠、截断或空白占位符。
- [ ] 所有标题无重复：每页章节标题只出现一次，无独立标题框与正文首段标题重复。
- [ ] 正文一般不少于 16 pt；首行缩进只用于连续中文段落，不用于表格/列表/标签。
- [ ] 红色只表达诊断关键证据；颜色对比、图片清晰度和表格可读性合格。
- [ ] 动画和切换克制且服务叙事；关闭动画时页面仍完整可读。

## 技术检查

- [ ] 逐页查看预览/渲染图，并抽查文本、对象、备注和关键富文本范围。
- [ ] 最终 `.pptx` 可以关闭后重新打开；页数、顺序和关键对象未丢失。
- [ ] 幻灯片放映可正常进入，动画/切换（如有）不阻塞讲解。
- [ ] 最终文件不是源文件或临时文件；工作副本、恢复点和最终版路径可区分。

## 交付说明模板

```text
已交付：<最终文件路径>
已保留：<源文件路径>；<工作/恢复副本路径>
修改范围：<内容、布局、动画/切换>
已完成：模板保真、病例一致性、脱敏、逐页视觉检查和重新打开验证。
待临床核实：<如无则写“无新增待核实项”；否则逐项列出>
```

除非用户明确同意，质检通过后仍保留工作副本和恢复点；不要自动删除。
