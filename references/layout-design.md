# 布局、字体与演示设计

## 布局变更等级

| 等级 | 含义 | 适用情形 |
| --- | --- | --- |
| 0 | 完全保持原 Layout | 法规/品牌要求极严，或内容变更极少 |
| 1 | 微调 | 只调整文字、间距、对齐和小图表 |
| 2 | 适度重排（默认） | 保持模板视觉语言，重组卡片、分栏和信息层级 |
| 3 | 创新布局 | 用户明确授权，且新结构明显提升医学叙事 |

任何等级都不得破坏背景、Logo、主题、核心母版元素和页码体系。先复制原布局中的视觉语言（栅格、边距、标题区、强调色），再改变信息组织。

## 页面结构建议

| 页面目的 | 优先结构 |
| --- | --- |
| 目录/章节 | 2×2 或纵向章节卡片，突出当前章节 |
| 现病史 | 左右分栏或单轴时间线：症状、检查、关键节点 |
| 查体/辅助检查 | 关键异常优先的简表；值、单位、范围、时点同列 |
| 诊断依据 | 五段证据链或“证据 → 解释 → 结论”卡片 |
| 鉴别诊断 | 条件对照表，只列有决策价值的差异 |
| 治疗经过 | 按时间的流程图或阶段卡片 |
| 转归/随访 | 里程碑时间线与结果对照 |
| 全科思考 | 2–4 张观点卡片，分别写观点、依据、可执行动作 |
| 困难与不足 | “问题 → 原因 → 改进”三列 |

一次页面只回答一个核心问题。内容过量时优先精简、拆分或使用补充页，不以缩小字体解决；必要时可增加页数，不局限于原模板页数。

以上结构仅为建议而非强制：同一页面可有多种呈现方式，全篇不必套用同一种表格或列举形式；优先按内容性质选择呈现方式，而非沿用固定模板。各列表/卡片/条目的数量仅为示例，按实际内容增减，不局限固定行数。

## 呈现方式与创新

- 不要求全篇套用同一表格或列举；根据内容性质选择最合适的可视化形式，同一份汇报中适度变换。
- 常用呈现手段（按内容组合，不必每次都用表格）：
  - 对比/鉴别 → 对照表、对照卡片、分栏
  - 时序/病程 → 时间线、流程图、里程碑
  - 因果/证据 → 证据链卡片、箭头/流程
  - 分类/并列 → 卡片、图标墙、标签
  - 数值/指标 → 简洁表格、强调数字、迷你条形
- 表格形式可变化：辅助检查/指标表格不固定行数与列数（如「项目|结果」或「项目|结果|参考范围」均可），也不强制用标准表格，可用卡片、标签、图标+数值等方式替代，按内容量与对比需求灵活选择。
- 工作内容页多样呈现：掌握疾病/学习观摩技能不限于彩色标签卡片，可用图标墙、分组列表、标签云、时间轴等；数量按实际内容增减。
- 变换形式时仍保持全篇视觉语言统一：配色、卡片圆角、图标风格、字号层级、间距一致。
- 创新以提升医学叙事为目标，不为“花哨”牺牲可读性；禁用动画后信息仍完整可读。

## 病例图片的呈现

- 图片服务于具体判断：一页优先展示一幅关键图及简短所见；CT/MRI 可选关键切片并配短序列视频，多时点对比保持相同视角、比例、窗宽窗位和清晰标注。
- 保持原图比例，不拉伸或过度裁切；使用箭头、圈注时避开病灶本身，并在文字中解释所指位置。检验单、影像截图先检查角标与边缘，再放大到投屏时可辨。
- 图下注明检查方式与采集时点。公开教学图片须显著标“示例图片，非本病例检查”及简短来源，完整署名和许可放入备注或资料来源页；真实病例图须与统一病例数据源对应。

## 字体、段落与可读性

- 以原模板字体体系为准；无明确规则时，标题约 24 pt、小标题约 20 pt、正文约 18 pt，正文不得低于 16 pt。
- 标题层级、字号、字重、颜色和对齐在同类页面保持一致。
- 标题不重复：同一章节标题全篇只出现一次；若某页既有独立标题框又有正文首段标题且文字重复，只保留独立标题框，删除正文首段重复标题。
- 正文用短句和项目符号；一行不宜过长，卡片间保持可辨留白。
- 中文叙述性段落可设首行缩进 2 个汉字；表格、指标、时间线标签、标题、项目符号和短语不设首行缩进。
- 不用空格或手动 Tab 伪造缩进。使用段落的 `FirstLineIndent`/等效段落格式，避免编辑后错位。
- 异常指标红色固定为 `#EE0000`；不要把整段或整表都染红。保留良好对比度，避免仅用颜色传达关键信息。

## 动画与切换

- 仅使用 Fade、Appear、Wipe 或简单 Morph；普通资料页宁少勿多。
- 诊断链、治疗流程可按讲解顺序逐步出现；同页尽量统一一种进入方式。
- 单页通常不超过 5 个动画元素；不使用 Bounce、Spin、随机、复杂路径、逐字动画或大幅 Zoom。
- 切换优先 Fade、Morph 或 Push。章节页可有轻微过渡；不要每页更换炫技效果。
- 演示即使禁用动画也必须完整可读，动画不能隐藏必要医学信息。
